**Document Version:** 1.0
**Template Version:** 1.0
**Template File:** `Sacrae_Preces.dotx`

# Purpose

This document defines the complete technical specification for the
Sacrae Preces Microsoft Word template.

It serves as the authoritative reference for:

- Typography
- Paragraph styles
- Character styles
- Table styles
- Page layout
- Headers and footers
- Colour palette
- Theme fonts
- Numbering
- Front matter
- Chapter layout

Any modifications to the template should be reflected in this document.
