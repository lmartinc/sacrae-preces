Publication Formats

Each volume should be prepared for:

Paperback
Hardcover (where appropriate)
EPUB
PDF
Versioning

Each publication receives a version number.

Examples:

Version 1.0 – First Edition
Version 1.1 – Minor corrections
Version 2.0 – Revised Edition
Source Control

All source documents remain under Git version control.

Published files are exported from tagged releases.

Archive

Previous editions are archived and never overwritten.

Each published edition remains reproducible from its Git tag.

Continuous Improvement

Reader feedback should be reviewed after publication.

Corrections and improvements are incorporated into future editions while maintaining doctrinal accuracy.
